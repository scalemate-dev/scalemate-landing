## Challenge

ZeptoLab вручну переносив рекламні креативи з NextCloud у Facebook Media Library через процес "скачай → перезалий". Це створювало три основні проблеми:

- Запуски кампаній затримувались через додаткові кроки завантаження і повільні цикли ітерацій
- Дублікати завантажень створювали безлад, який потребував ручного чищення
- Ручне управління файлами стало bottleneck при масштабуванні операцій

---

## Solution

Scalemate розробив кастомну інтеграцію NextCloud → Facebook з завантаженням в один клік:

- **Inclusion & Exclusion rules** — селективне завантаження файлів
- **Автоматичне запобігання дублікатам** — переносяться тільки нові креативи
- **Custom File Selection** — команда контролює точність завантажень

---

## Results

- Автоматизація усунула ручні кроки — завантаження в кілька кліків
- 70% скорочення часу вивільнило команду для фокусу на креативній стратегії і перформансі кампаній
- Кастомна інтеграція дозволила масштабуватись без збільшення навантаження
