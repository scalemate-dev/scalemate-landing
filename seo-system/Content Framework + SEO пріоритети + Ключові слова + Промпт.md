# **4\. Як це виглядає як SEO Strategy** 

## **Cluster structure:**

FEATURE (pillar)

   ↓

USE CASE (intent)

   ↓

SOLUTION (ICP)

**Те як Google розуміє SaaS продукт** і **як користувач рухається у funnel**

---

## **1\. FEATURE \= PILLAR**

### **Що таке pillar?**

Pillar — це **основна тематична сторінка**, яка:

* має найширшу тему  
* пояснює core capability продукту  
* збирає authority

У нас:

* Bulk Launch  
* Automation Rules  
* Cloud Sync  
* AI Agent

---

### **Чому feature \= pillar**

Бо Google будує topical authority від широкого до вузького.

Example:

bulk ad creation tool  ← широка тема

   ↳ launch hundreds of ads in minutes ← use case

Якщо немає pillar — Google не розуміє контекст.

---

## **2\. USE CASE \= SEARCH INTENT**

Use case — це **запит, з яким реально приходять люди**.

Не “що це за фіча”, а:

“як вирішити проблему”.

Тому у вас:

* bulk-ad-launch  
* automate creative upload  
* scale campaigns faster

Це **problem-solution pages**.

---

### **Що таке intent?**

Search intent \= що людина хоче зробити.

В SaaS є 3 типи:

| Intent | Example |
| ----- | ----- |
| Informational | what is ad automation |
| Problem | automate facebook uploads |
| Solution | bulk ad launch tool |

Use cases ловлять **Problem \+ Solution intent**.

Саме тому вони — середній рівень кластера.

---

## **3\. SOLUTION \= ICP (Identity Pages)**

Solution pages — це:

- Scalemate for Media Buyers  
- Scalemate for Creative Teams  
- Scalemate for Marketing Leaders

Це про: “Це для мене?”

Google це теж розуміє.

Це називається:

### **Role-based SEO**

Searches:

* tools for media buyers  
* marketing automation for founders

---

Реальний шлях виглядає так:

1\. Людина шукає рішення болю → Use Case

2\. Розуміє, що це feature → Pillar

3\. Перевіряє: це для моєї ролі? → Solution

Але SEO authority будується навпаки:

Pillar → Intent pages → ICP pages

        BULK LAUNCH (pillar)

            /        \\

           /          \\

bulk-ad-launch     scale campaigns faster  ← intent

           \\          /

            \\        /

         media buyers page   ← ICP

---

НЕ запускай одразу всі use cases.

Зроби:

* 4 use cases  
* 1 solution  
* 2 features

І побудуй **internal link loop**.

Інакше Google не побачить cluster authority.
