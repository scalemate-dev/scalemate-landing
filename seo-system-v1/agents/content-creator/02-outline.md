# Step 2 — Generate Outline

Створити outline (H2/H3 з коротким описом кожної секції):

```markdown
## Draft Outline: [Title]

H1: [proposed headline]

TL;DR (draft, 3-5 bullets):
  - ...

H2: [Section 1]
  - Key points: ...
  - Data to include: ...

H2: [Section 2]
  ...

H2: FAQ
  - Q1: ...
  - Q2: ...

Internal links planned: [list of pages]
First-hand experience markers planned: [що саме буде]
```
