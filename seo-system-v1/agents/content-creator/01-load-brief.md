# Step 1 — Load Brief

> **Trust the brief.** Discovery вже валідував keyword, обрав content type і трек, виконав title/meta pre-work, прописав unique angle. Content-creator **не передвибирає** ці поля.

## Прочитати brief'и витягти:

| Поле з brief | Куди йде |
|---|---|
| **Content type + Track** | визначає який template з [`rules/content-writing.md` → 2.3 Типи контенту](../../../seo-system/rules/content-writing.md#L137) |
| **Primary keyword + secondary** | для keyword integration ([`rules` → 3.3](../../../seo-system/rules/content-writing.md#L369)) |
| **JTBD group** | визначає messaging angle ([`rules` → 8 JTBD Messaging Framework](../../../seo-system/rules/content-writing.md#L1043)) |
| **Funnel stage (TOFU/MOFU/BOFU)** | впливає на CTA / depth |
| **Unique Angle** | differentiator vs top-3 SERP |
| **Title/Meta Direction** | ground для фінального title — content-creator пише фінал по [`rules` → 4.1](../../../seo-system/rules/content-writing.md#title-meta-prework) |
| **Must Include** (internal links, first-hand markers, data points, schema) | hard requirements у draft'і |
| **Input Needed from Natalia** | чи є unresolved inputs до старту? Якщо так → перевірити чи отримані; якщо ні → див. [Step 5](05-input-request.md) |

## Якщо brief не містить обов'язкових полів

→ Не починати draft. Повернути «brief incomplete: [missing fields]» і escalate. Discovery повинен був заповнити — не виправляємо це у content-creator.
