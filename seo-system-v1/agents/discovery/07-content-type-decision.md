# Step 7 — Content Type Decision

На базі попередніх кроків визначити тип контенту:

| Type | Коли вибираємо | Template |
|---|---|---|
| **blog** | Educational / how-to / topic explainer | rules/content-writing.md Track A |
| **comparison** | "Scalemate vs X", "alternatives to X" | Track E |
| **use-case / solution** | Конкретний JTBD / industry / role landing | Track D |
| **case-study** | Реальний клієнт + cifri (Appflame, Promin) | Track C |
| **hub / pillar** | Велика тема, кластер 8-12+ супутніх статей | Track F |
| **resource / template** | Безкоштовний шаблон / чекліст / калькулятор | Track G |
| **product page update** | Existing product page має CTR/messaging gap | Track B |

## Inputs to decision

- **Funnel stage** ([Step 2](02-funnel-assessment.md)): BOFU → comparison / case-study; MOFU → blog how-to / use-case; TOFU → blog explainer / hub
- **Existing check** ([Step 3](03-existing-content-check.md)): UPDATE → не новий type, апдейтимо в існуючому форматі
- **Competitive gap** ([Step 5](05-competitive-gap.md)): якщо top-3 — listicles, наш формат теж listicle (з кращою структурою)
- **Cluster maturity:** hub/pillar створюємо ТІЛЬКИ коли в кластері вже 8-12+ опублікованих статей

## Output

```
Content type: [blog / comparison / use-case / case-study / hub / resource / product-update]
Template: [rules/content-writing.md Track X]
Target length: [N words] — на 20-40% більше за best top-3 competitor
JTBD group: [A / B / C / D] — з context/icp/jtbd-messaging.md
```
