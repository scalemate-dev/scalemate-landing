# Step 9 — Generate Topic Brief

Зібрати усі попередні кроки у єдиний Topic Brief:

```markdown
# Topic Brief: [Topic]

## Keyword Data
- Primary: [keyword] (Vol: X, KD: Y, CPC: $Z)
- Secondary: [2-3 related keywords]
- Trend: [rising / stable / declining]
- Stream: [1: data-driven / 2: pain-driven]

## Existing Content Check
- Matching page: [URL or NONE]
- Cannibalization risk: [YES/NO]
- Decision: [UPDATE existing / CREATE NEW]
- Why: [reason]

## Funnel & Conversion
- Funnel stage: [TOFU / MOFU / BOFU]
- Steps to sign-up: [1 / 2-3 / 3+]
- ICP fit: [N/5]
- Product page link: [direct / indirect / weak]

## SERP Analysis
- Quick check passed: [YES — intent matches]
- Top 3: [domain — title — type]
- SERP features: [AI Overview / PAA / Videos / etc]
- Dominant intent: [informational / commercial / navigational]
- Can we win: [YES — reason / NO — reason]

## Competitive Gap
- What top-3 cover well: [summary]
- What they miss / our differentiation: [specific gaps]
- Backlink realism: [can we beat]

## ICP Pain Research
- Source: [inherited from intel brief / ad-hoc]
- Pain quotes: [3-5 quotes з лінками]
- Pain language: [фрази]
- Scale: [час/гроші]
- Current workarounds: [...]
- Emotional triggers: [...]
- Thread activity: [N тредів, M коментарів]
- Translated queries: [validated через Ahrefs]

## Content Plan
- Type: [blog / comparison / case-study / use-case / hub / resource / product-update]
- Template: [rules/content-writing.md Track X]
- Target length: [N words]
- JTBD group: [A / B / C / D]
- Funnel stage: [TOFU / MOFU / BOFU]
- ICP: [UA Manager / Founder / etc]

## Title/Meta Direction
- SERP patterns pos 1-3: [summary]
- Brand in title: [YES / NO]
- Power elements: [list]
- absoluteTitle flag: [YES / NO]
- Draft directions: [1-2 candidates, не фінал]

## Unique Angle
[1-2 sentences: чому наша стаття буде відрізнятись від top-5]

## Must Include
- [ ] Internal links: [specific pages to link to]
- [ ] First-hand experience markers: [what specifically]
- [ ] Data points needed: [numbers/screenshots]
- [ ] Schema: [which type]

## Expected Impact
- Estimated monthly clicks if top-3: [X]
- Business value: [TOFU/MOFU/BOFU × ICP fit]
- Pain-validated bonus (Confidence +1): [YES — inherited from intel / NO]

## Input Needed from Natalia
- [ ] [Specific input 1 — e.g. "screenshot of rules setup"]
- [ ] [Specific input 2 — e.g. "Appflame case numbers"]
- Or: "No input needed — can write from existing materials"
```
