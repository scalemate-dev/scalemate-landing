# Stage 1 — Content-Ops Expert Panel

Викликати skill `content-ops` на draft:

- Зібрати панель 7-10 експертів
- **Target score: 90+**
- Max 3 rounds iteration
- Якщо після 3 rounds < 90 → повернути з чесним score + top weaknesses

## Якщо score < 90

→ Повернути draft content-creator'у з конкретними issue pointers через [Stage 5 FAIL](05-output-and-pipeline.md)
→ **НЕ пропускати далі** на Stage 2

## Якщо skill недоступний

Див. [README → Skills disclaimer](README.md#skills-disclaimer). Позначити stage як skipped, продовжити на Stage 2.
